## How to try one yourself

1. Pick a video and open its page in [`prompts/`](prompts/). Copy the prompt, or borrow the idea from the author's post.
2. Give it to Claude Fable 5.5 (Claude Code, the Claude app, or any agent running Fable 5.5).
3. Ask for the result as code: a single HTML file with Canvas, SVG or Three.js, plus a soundtrack if you want one. Record the page to get a video.

Want your agent's videos to look finished? [Skillry](https://skillry.dev/skills?output=video&utm_source=github&utm_medium=readme&utm_campaign=awesome-fable5-5-videos) has ready-made video Skills for launch films, motion graphics and explainers.
